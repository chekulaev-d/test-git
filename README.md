1. git status
2. git add [files] - добавляет файлы в stage
3. git commit -m "comment"
4. git log(показывает подробную информацию о наших записях)/ git log --oneline(показывает краткую запись о наших файлах)
5. git remote -v(показывает ссылки на репозиторий)
6. git push [rep_link] [branch_name]
7. git reset (отменяет последнее изменение)
8. git diff (показывает какие были изменения)
9. git reset --hard(полностью отменяет все изменения и возвращает файл в первоночальном виде)
10. git branch(показывает ветки которые есть)
11. git checkout (делает переключение между ветками)
