1. git status
2. git add [files] - добавляет файлы в stage
3. git commit -m "comment"
4. git log(показывает подробную информацию о наших записях)/ git log --oneline(показывает краткую запись о наших файлах)
5. git push [rep_link] [branch_name]
6. git reset (отменяет последнее изменение)
7. git diff (показывает какие были изменения)
8. git reset --hard(полностью отменяет все изменения и возвращает файл в первоночальном виде)
